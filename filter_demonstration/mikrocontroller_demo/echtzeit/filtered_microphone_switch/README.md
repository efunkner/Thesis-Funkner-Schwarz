# Echtzeitfilterung mit verschiedenen Filtern - Mikrofon

Dieses Programm basiert auf dem `filtered_microphone` und erweitert dieses mit einer Switch-Case, bei welcher über den MODE-Taster des Lyrat zwischen verschiedenen Filtern gewechselt werden kann. Bei dem Switch-Case wird zwischen den `FilteredStreams` über Tasterdruck gewechselt.

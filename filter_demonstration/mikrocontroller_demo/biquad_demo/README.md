# Filterdemonstration

Das `biquad_demo.ino` Programm filtert ein generiertes Rechtecksignal mit einem Biquad-Filter. Die Arduino IDE ermöglicht im Serialplotter die gefilterte Impulsantwort zu betrachten.
Für diese Demonstration werden keine weiteren Bibliotheken für die Arduino IDE benötigt und kann auf jedem Arduino fähigen Mikrocontroller verwendet werden.
